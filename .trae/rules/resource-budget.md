# 本机开发与上下文预算

- 本项目在 16GB Mac 上开发。恢复运行时先读 `docs/LOCAL_RECOVERY.md`，按当前文件与进程验证，不沿用旧对话的 PID、成功结论或重试命令。
- 只用 `npm run dev` 启动本地服务；它有端口检查、Webpack、线程与堆限制、进程组资源监控。不要用裸 `next dev`、并行启动或自动重启绕过保护。
- 先检查 3000 端口，有服务时验证并复用；启动一次，串行验证 `/home`、`/library`。请求必须带超时，同一路径失败两次后停止，检查日志与 `.dev-runtime/status-3000.json`，不要连续 curl 或重复拉起服务。
- 不同时运行开发服务、生产构建和全套测试；不要全局 kill Node 或终止其他应用。
- 按需读取源码；跳过 `.trae/.ignore` 中的产物、依赖、素材和参考仓库。大文件先定位行号，再读取片段；必要时才查框架依赖内的官方文档。
- 每个阶段只解决一个问题，输出简短的事实、验证结果与下一步。用 `docs/LOCAL_RECOVERY.md` 交接，不把整段旧聊天、大量日志或整仓源码塞进新上下文。
- 遵循 AGENTS.md 与 DESIGN.md；运行恢复不扩展为重构、复刻、支付接入或全项目功能开发。不要读取、打印或上传 `.env` 的值。
