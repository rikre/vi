## 四、全局 UI 设计规范

### 4.1 设计系统

| 维度 | 规范 |
|---|---|
| 主题 | 暗色（#0d0d0d 背景） |
| 主色 | brand 亮绿（#D4FF3F） |
| 字体 | 系统默认 + 14px 基准 |
| 圆角 | 8px（小）/ 12px（中）/ 16px（大） |
| 间距 | 4/8/12/16/24/32/40px |
| 边框 | `border-white/[0.06]` / `border-white/[0.12]` |
| 卡片 | `bg-white/[0.02]` + `border-white/[0.06]` |

### 4.2 组件规范

| 组件 | 规范 |
|---|---|
| 按钮-主 | `bg-brand text-brand-foreground hover:bg-brand-hover` |
| 按钮-次 | `border-white/[0.12] bg-white/[0.04] hover:bg-white/[0.08]` |
| 输入框 | `h-10 rounded-lg border-white/[0.2] bg-white/[0.1]` |
| Tab | 选中 `text-white` + 下划线 / 未选 `text-white/40` |
| 卡片 | `rounded-xl border-white/[0.06] bg-white/[0.02] p-4` |

### 4.3 图标规范

- 使用 Lucide React 风格
- 自定义图标在 `src/components/icons.tsx`
- 尺寸：`size-4`（小）/ `size-5`（中）/ `size-7`（大）
