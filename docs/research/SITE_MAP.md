## 二、逐页区块清单（元素不缺的对照基线）

### /zh/home 创作（Bollo | 一人一座梦工厂）
1. 顶部限时活动轮播（大赛/视频特惠，可暂停/关闭）
2. Hero：做短剧/写剧本 双入口 + Agent模式/人工模式 开关 + 风格选择 + 16:9/9:16 + 创建项目
3. 快捷入口：生图片/生视频/资产广场/重制工坊
4. 红果热榜 / 海外热榜（双榜）
5. 爆款IP库（卡片 + 探索更多）
6. 数字艺人
7. 数字剧场
8. 右上角常驻：用户群/邀请有礼/订阅计划

### /zh/project 项目
1. tab（短剧/剧本，带计数）
2. 搜索 → 排序（最新创建）
3. 模式筛选：全部/剧本/重绘/**影棚**/自由/其他 ← "影棚"为新增
4. 项目卡列表 / 空状态（未找到项目 + 进入创作）

### /zh/script/market 剧本超市（VibeVideo）
- 主体为跨域 iframe（`art.bollo.video?embed=1`）。**克隆决策：本地重建为原生页面**（iframe 无法保证一致性与可维护性）
1. tab：高分剧本（评估总分前20）/ 全部剧本
2. 筛选：搜索 + 评级(S+/S/A+/A/B及以下) + 频道(男频/女频) + 类型(实拍/AIGC) + 发行市场(国内/北美)
3. 悬浮"打开剧探"按钮

### /zh/library 资产
1. 5 tab 带计数：角色库/场景库/道具库/音色库/数字艺人
2. 搜索 + **导出**按钮
3. 多维筛选：范围/地区/性别/年龄阶段/风格/是否有参考音色/项目筛选
4. 创建按钮 + 卡片列表（含"Bollo 精选 / N个版本"版本组）

### /zh/tools 工具（通用生成工作台，非工具卡片页）
1. 搜索/日期筛选/筛选器/**切换旧版**
2. 历史记录区（空状态）
3. 底部创作模块：参考素材 tab（图片/音频/视频）+ 提示词框(0/8000) + 创作模式（多参视频生成）+ 规格（9:16|720p|5s）+ 模型（Seedance 2.0 多参特惠版）+ 标签 + 提交（显示积分消耗 42）
4. 悬浮球：素材库/反馈中心

### /zh/skills Skills 广场
1. 顶部对话输入栏：创作灵感 + 添加附件/选择模型/选择Skill/进入对话
2. 内容 tab：**Skill/收藏/我的/对话**（?tab=skills/favorites/mine/chats）
3. 分类 8 个：专业影视/商业广告/短剧漫剧/动漫游戏/音乐MV/自媒体创作/通用技能/发现
4. 技能卡网格：视频封面/标题/描述/作者·使用数/使用/收藏
5. "对话" tab：双栏聊天界面（搜索对话/已归档）
