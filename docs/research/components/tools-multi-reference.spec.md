# Tools / multi-reference 对齐 Specification

来源截图：`docs/design-references/clone-tools/online-1440.png`（线上 1920×992 viewport，多参视频生成 tab 已登录）
对应本地文件：`src/components/tools/tools-studio.tsx`（结构和控件顺序与线上同源，下面是 6 处需对齐的差异）

## 页面拓扑（线上）
- 滚动容器 `library-v2-scroll tool-platform-scroll h-screen overflow-y-auto`（页面级滚动，不是 body）
- 内容容器 `max-w-[1500px] mx-auto`（本地已对齐 max-w-[1500px]）
- 顶部筛选条：搜索（h-10 rounded-lg）/ 日期 input / 两个「全部」下拉（各 h-[34px] rounded-[9px] border）/ 右边「切换旧版」链接（h-[34px] rounded-[9px] border）
- 历史网格 `.library-v2-grid`：column = 363px * 4，gap = 28px 16px（本地 grid-cols-4 gap-4 基本对齐，仅行距 28px vs 16px）
- 历史卡片 `.library-v2-card`：media 363×158（约 21:9）object-cover；body 标题 truncate + 元信息行 + 操作行（添加标签 / 重新编辑 / 超分）
- 底部创作面板 `section.tool-platform-module` sticky bottom-3 z-20 max-w-4xl mx-auto rounded-2xl border p-3 sm:p-4
- 右侧浮动素材库入口按钮 brand 圆形（本地已有）

## 面板（线上精确值，需替换本地）

- 背景 `rgba(61,61,61,0.76)` + `backdrop-blur-sm`（本地 `bg-surface-elevated/80` 偏实）
- 边框 `rgba(255,255,255,0.2)`（本地 border-white/20 一致）
- 圆角 16px，padding 12px（sm 16px）
- 底部间距 `bottom-3`（本地 `bottom-0`）

### 上传卡（线上精确值）
- 尺寸 68×68（本地 112×112）
- 圆角 12px、背景 `#515151`（无实边框、无虚线）
- 标题文字「图片」「音频」「视频」（无「上传」二字，本地是「上传图片」）
- 图标线性 image / audio-lines / video（lucide）
- 布局：与 textarea 在同一水平行的左侧（`#tool-platform-reference-tray` mb-3 flex gap-2），不是独立在 textarea 之上

### textarea（线上）
- 高度 80px、font 14、rounded-xl、border-secondary
- placeholder 与本地完全一致（已对齐）
- 字数计 0/8000 右下

### 参数控件行（线上）
- 组合规格按钮：`9:16 | 720p | 5s` 合并成一个 h-[34px] rounded-[9px] 按钮，点击弹规格面板；本地是拆开的独立下拉
- 创作模式下拉：`多参视频生成`（buttonClass w-[112px] 本地已对齐）
- 模型下拉：`Seedance 2.0 多参（特惠版）`（w-[160px] 本地已对齐）
- 标签下拉
- 右侧：CTA 硬币图标 + `42`，bg `#C8FF71` color 黑，h-[34px] px-4 rounded-xl

### 历史卡元数据（线上）
- 模型名（Seedance 2.5 多参（特惠版）/ 腾讯 1080P 超分）
- 「720p」「15s」「124 积分」三段空格分隔
- 操作行：「添加标签」「重新编辑」「超分」
- 本地缺元数据与「超分」操作、媒体用 16:9（aspect-video）非线上 21:9

## 决定保留本地交互（不做伪功能）
- 素材库 Modal / 优化提示词 / 模板提示词：本地交互更完整，不动
- 「对齐」范围限于视觉/结构/文案，不虚构后端行为
