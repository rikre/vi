# 工具页提取与实施 Spec（2026-10-25）

## 证据来源与边界

- 线上：`https://bollo.video/zh/tools`，必须为用户登录后的真实工具页；未登录跳转到首页或登录弹窗的截图不得作为依据。
- 默认截图：`docs/design-references/bollo-audit/tools-1440.png`、`tools-768.png`、`tools-390.png`。
- 弹层截图：`tools-library-1440.png`、`tools-feedback-1440.png`。
- 样式来自浏览器 DOM、`getComputedStyle()`、CSSOM 与实际点击/切换结果；页面为点击驱动，无滚动动画库。
- 本地只实现前端交互和 mock 记录，不调用真实生成、扣积分、上传或反馈接口，不编造未提取到的价格。

## B01 页面外壳与历史区

- 页面主背景提取为 `rgb(40,40,40)`，外层/抽屉为 `rgb(19,19,19)`；实现优先映射现有 `surface` / `background` 语义 token，不新增硬编码色板。
- 字体：`"HarmonyOS Sans SC Regular", sans-serif`。
- 桌面共享侧栏 64px；内容容器最大宽度 1500px，1440px 视口下内容 x=96、y=33、宽 1300px。
- 顶部工具栏右对齐：搜索 240×34、日期 115×34、两个筛选器各 128×34、切换旧版 74×34。
- 控件高 34px、圆角 9px，背景 `rgba(255,255,255,.1)`，边框 `rgba(255,255,255,.11)`。
- 搜索 placeholder：`搜索标题、提示词或标签`。
- 日期默认显示 `年 / 月 / 日`；用户筛选为 `全部 / Phone User 7767`；类型筛选为 `全部 / 视频 / 图片 / 音频`。
- 旧版地址：`https://bollo.video/zh/tools?legacy=1&tab=multi-reference`，使用原生 `<a>`。
- 空状态图标为品牌色 sparkle，标题 `暂时没有内容`，描述 `在下方工具模块中开始创作`。
- 本地生成后显示 mock 历史卡片；搜索、日期、用户、类型筛选真实过滤本地记录，无结果显示同一空状态。

## B02 底部创作面板

- 面板最大宽度 896px，桌面居中并固定在内容底部；背景 `rgba(61,61,61,.76)`，圆角 16px，1px 白色 20% 边框，`backdrop-filter: blur(8px)`。
- 上传块 68×68、圆角 12px，背景 `rgb(81,81,81)`；实现使用语义化白色透明度近似，不新增 token。
- 提示词框高 133px，最大 8000 字，默认计数 `0/8000`。
- 底部控件向上弹出菜单；顶部筛选向下弹出。所有菜单支持选中、点击外部关闭和 Escape 关闭。
- 创作模式共五项：`多参视频生成`、`图片生成`、`音乐生成`、`去字幕`、`视频超分`；切换后上传区、提示词、规格和积分按钮同步变化。

### 多参视频生成（默认）

- 上传：图片 `image/*`、音频 `audio/mpeg,audio/mp3,.mp3`、视频 `video/mp4,video/quicktime,.mp4,.mov`，允许多选。
- placeholder：`在此描述视频内容，包括情节、运镜、对白、音效或者背景音乐等，上方可选择参考的视频（最多3个）、图片（最多9张）、音频（最多3个），也可直接@参考内容`。
- 默认模型：`Seedance 2.0 多参（特惠版）`。
- 模型列表：`Seedance 2.0 多参（特惠版）`、`Seedance 2.0 多参`、`Seedance 2.5 多参（特惠版）`、`Seedance 2.5 多参`、`海螺 H3 多参`、`Seedance 2.0 Mini 多参`；菜单无价格文本，不得补写。
- 规格默认 `9:16 | 720p | 5s`；比例 `9:16 / 16:9 / 21:9 / 1:1`，分辨率 `720p / 1080p`。
- 时长 range 索引 0–11 对应 4–15s，默认索引 1 为 5s。
- 标签输入 `maxlength=64`，placeholder `可选，用于筛选历史`；默认按钮积分 `42`。

### 图片生成

- 仅显示图片上传；placeholder：`在此描述图片内容，包括主体、场景和风格等；上方可添加参考图片。`
- 默认规格 `9:16 | 2K`；比例 `21:9 / 9:16 / 4:3 / 1:1 / 16:9 / 3:4`，分辨率 `2K / 4K`。
- 默认模型按钮 `模型 (1)`，Seedream 4.5 默认生成数量 1；默认积分 `3`。
- 模型菜单：
  - `Seedream 4.5 (2K-3 / 张)`：效果均衡，色彩艳丽。
  - `Seedream 5.0 Lite (2K-3 / 张)`：善于改图，文字绘制能力强。
  - `Seedream 5.0 Pro (2K-8 / 张)`：编辑可控，效果自然。
  - `Nano Banana (2K-4 / 张)`：语义理解强，控制力强。
  - `Nano Banana 2 (2K-8 / 张)`：理解能力强，改图准确。
  - `Nano Banana Pro (2K-10 / 张)`：语义理解更强，控制力更强。
  - `GPT Image 2 Low (2K-1 / 张)`。
  - `GPT Image 2 Medium (2K-8 / 张)`。
  - `GPT Image 2 High (2K-32 / 张)`。
  - `GPT Image 2.5 High (2K-7 / 张)`。
  - `混元生图3 (1K-2 / 张)`：高质量文生图，暂不支持图生图。
  - `Midjourney 7 (1K-3 / 张)`：艺术风格突出，暂不支持图生图。
- 只将 Seedream 4.5 作为默认选中，不推断菜单其他勾号的多选语义。
- `优化提示词` 与 `模板提示词` 提供本地可验证行为：优化为当前文本补充镜头/风格描述，模板填入可编辑示例，不调用 AI 接口。

### 音乐、去字幕、视频超分

- 音乐生成：无上传块，placeholder `在此描述音乐内容，包括风格、情绪和节奏等。`，积分 `10`。
- 去字幕：仅视频上传，无 textarea，按钮 `0.5 积分/秒`。
- 视频超分：仅视频上传，无 textarea；模型 `腾讯 720P 超分 / 腾讯 1080P 超分 / 火山720P超分 / 火山1080P超分`；按钮 `1 积分/秒`。
- 以上模式提交均只创建本地 mock 记录；缺少该模式必填输入时显示内联提示，不发请求。

## B03 素材库与参考项

- 右下悬浮品牌色按钮 `aria-label=打开素材库`，使用 `LayoutGridIcon`。
- 抽屉右侧 384px、全高、z-50，包含 `素材库 / 搜索素材... / Bollo 精选 / 全部 / 角色 / 场景 / 道具`。
- 分类与搜索真实过滤；点击素材加入当前模式参考项，不向 textarea 填名称。
- 参考项支持 `预览图片 / 删除`；预览为带 `role=dialog`、`aria-modal=true` 的模态框，Escape 关闭并恢复焦点。

## B04 反馈中心

- 从共享侧栏 `帮助与反馈` 打开；仅 `/tools` 使用本对齐版本，其他页面保持既有反馈组件。
- 桌面 840×608，主背景 `rgb(45,45,45)`，左侧 240px、背景 `rgb(56,56,56)`；移动端改为可滚动单栏。
- 顶部 tab：`广播消息 / 意见反馈`，使用 ARIA tablist；反馈页包含 `反馈记录 / 新建反馈 / 输入主题 / 请详细描述你的反馈... / 上传图片 / 发送`。
- 新建反馈选择本地图片并显示文件名；主题和描述必填，发送后写入本地反馈记录并可查看。广播消息 tab 展示本地说明，不发网络请求。
- 使用共享 `Modal` 获得焦点圈定、Escape 关闭与焦点恢复。

## B05 响应式与共享外壳

- `max-width:900px`：顶部工具栏纵向排列，搜索与工具区全宽，内容水平 padding 18px。
- 768px：搜索独占一行，其余控件换行；生成面板保持底部居中。
- 390px：顶部控件和生成面板底部控件多行排列，面板不横向溢出。
- 线上 390px 为汉堡菜单，本地依项目硬约束保留共享 64px 侧栏；这是已记录偏差，本任务不改全站移动外壳。
- `/tools` 隐藏共享 `TopBar` 的充值/订阅条及右下 `CourseFab`；其他路由默认行为不变。

## 实施契约与验收

1. `src/app/tools/page.tsx` 只负责组合 `AppShell` 与客户端工具台；交互放在 Client Component。
2. 所有按钮、菜单、tab、上传、参考项、反馈和生成都有实际状态变化；禁止死按钮和静默异常。
3. 图标统一从 `@/components/icons` 引入；不直接导入 `lucide-react`，不使用 Tailwind 默认色板。
4. 测试覆盖默认内容、五模式切换、筛选/生成、素材添加预览删除、反馈提交及共享外壳默认行为。
5. 串行执行相关 Vitest、`npx tsc --noEmit`、改动文件 ESLint、生产构建；再启动一次受控服务完成 1440/768/390 截图，验证后立即停服务。
6. 既有全量 lint 错误不得被伪报为通过；Round 4 总门槛未全部通过时保持阻塞并如实记账。
