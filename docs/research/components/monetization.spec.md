# 商业化体系 Spec（Monetization）

> 状态：V1 定稿（经两轮优化循环）
> 范围：首页流量层（通告栏 + 弹窗）+ `/pricing` 定价页（积分锚定 + 会员 + FAQ）
> 设计参考：docs/design-references（图1 会员档位、图2 权益矩阵、图3 FAQ、图4/5 首页弹窗）

---

## 1. 总体框架

三层漏斗：

| 层级 | 载体 | 目标 | 核心动作 |
|---|---|---|---|
| 流量层 | 首页顶部通告栏 + 轮播弹窗 | 曝光 → 点击 | 模型特价钩子（Seedance 2.5 一秒一元） |
| 转化层 | `/pricing` 页 | 点击 → 付费 | 积分锚定（首充）→ 会员升级（年费优先） |
| 留存层 | 会员权益 + FAQ | 付费 → 续费 | 年费锚定、权益矩阵、答疑降阻 |

### 1.1 货币体系（已确认：统一积分）

- 单一货币「积分」：**1 元 = 10 积分**
- 充值、会员均发放积分；所有模型/功能消耗统一扣积分
- 扣除顺序：赠送积分 → 会员积分 → 充值积分（FAQ 明示）
- 不引入第二币种，降低认知成本

## 2. 流量层（首页）

### 2.1 顶部通告栏

- 位置：首页顶部，全宽，可关闭（× 记忆当日关闭状态）
- 文案：`🔥 Seedance 2.5 首发特价 1元/秒 ｜ 充值积分最高加赠50%`
- 右侧 CTA：「去充值」→ `/pricing`

### 2.2 首页轮播弹窗

- 触发：进入首页自动弹出；频控 **每日 1 次**（localStorage 记录日期）
- 结构：轮播 2 页，底部圆点指示，右上角 × 关闭
- **P1 模型特价卡**（参考图4）：
  - 左侧主视觉图（Seedance 2.5 1080p）
  - 活动时间标签：`活动时间：2026.8.14 14:00 - 9.17 14:00`
  - 标题：`Seedance 2.5 1080p`
  - 卖点 3 条：原生1080p搭载10bit色彩 / 完美适配高预算精致影级拍摄手法 / 光影效果逼真高还原
  - 价格行：`无参考视频 积分 83/s`（划线原价 115）；`有参考视频 积分 54/s`（划线原价 75）
  - CTA：`Seedance 2.5 1080p 限时72折` → `/pricing`
- **P2 充值加赠卡**（参考图5）：
  - 大标题 `Seedance 2.5 首发上线`
  - 副文案：`Seedance 2.0 mini 4折 ｜ Seedance 2.0 fast 75折`、`充值最高加赠70%`
  - CTA：「立即充值」→ `/pricing`

## 3. 转化层（`/pricing` 页）

页面结构（自上而下）：模型特价 banner → 积分充值（6 档）→ 会员订阅（个人/团队 × 月/季/年 × 3 档 + 权益矩阵）→ FAQ。

### 3.1 积分充值锚定（6 档）

| 档位 | 价格 | 得积分 | 加赠 | 设计意图 |
|---|---|---|---|---|
| 首充专享（终身一次） | ¥10 | 150 | +50% | 破冰转化 |
| 档2 | ¥50 | 500 | — | 纯锚点 |
| 档3 | ¥100 | 1,100 | +10% | 锚点 |
| 档4 | ¥300 | 3,450 | +15% | 锚点 |
| 档5（主力档，推荐标记） | ¥600 | 7,200 | +20% | 主力转化 |
| 档6 | ¥950 | 10,500 | 送1000等值 | 大 R 档 |

- 首充成功后二次引导「升级年费会员」（支付成功页 CTA）

### 3.2 会员订阅（已确认：个人3档 + 团队3档）

切换维度：
- 身份：个人 / 团队
- 周期：月付 / 季付 / **年付（推荐，低至49折，文案数据驱动）**

#### 个人版（年付折合月价）

| 权益 | 轻量版 | 专业版 | 旗舰版 |
|---|---|---|---|
| 年付折合月价 | ¥86/月 | ¥239/月 | ¥519/月 |
| 月付原价 | ¥133/月 | ¥399/月 | ¥1064/月 |
| 月积分 | 1,620 | 3,920 | 9,240 |
| 最多约图片 | 810 张 | 1,960 张 | 4,620 张 |
| 最多约视频 | 810 秒 | 1,960 秒 | 4,620 秒 |
| 视频模型折扣 | 最低7折 | 最低6.7折 | 最低6.4折 |
| 图片模型折扣 | 6.4折 | 6.4折 | 6.4折 |
| 分镜并发 | 10 | 13 | 20 |
| 去水印导出 | ✓ | ✓ | ✓ |
| 1080p 高清导出 | — | ✓ | ✓ |
| 4K 超清导出 | — | — | ✓ |
| 更稳定的模型服务 | ✓ | ✓ | ✓ |
| 生成队列 | 标准 | 优先 | 专属 |

#### 团队版

- 定价 = 对应个人档 ×2，含 **3 席位**
- 积分池 = 个人档 ×2，**席位共享池**（单席位成本比个人版低约 33%，核心卖点）
- 权益同个人版对应档

#### 年费会员专属权益（引导年付）

- 年付 67 折（季付 85 折 / 月付原价）
- 加赠 2 个月等值积分
- 活动期间折扣锁定
- 专属客服

#### 卡片展示规范

- 主视觉：折合月价 + 「年省 ¥XXX」，弱化年付总价
- 限时特惠标签：`限时特惠｜Seedance2.5 720p 低至 X 元/秒`
- 划线原价 + 折扣角标（合规：明示原价与活动期限）

## 4. 数据埋点（闭环）

| 事件 | 参数 |
|---|---|
| banner_impression / banner_click | 通告栏 |
| popup_impression / popup_click | page=1/2, cta |
| pricing_tier_click | tier, price |
| first_charge_success | amount |
| upgrade_to_annual_click | from=first_charge |
| member_subscribe | plan, cycle, identity |

核心指标：弹窗 CTR、各档点击分布、首充→年费升级率、支付漏斗转化。
