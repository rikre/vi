## 功能概述

**提示词工作台（Prompt Workbench）** 是技能广场中的自定义创作技能系统，允许用户创建、编辑、管理和复用提示词创作规则。

### 核心能力

1. **三种模式**：分镜提示词 / 单视频润色 / 去瑕疵
2. **内置技能**：镜头叙事、动作与运镜、角色一致性、画面稳定（4 个预设规则）
3. **自定义技能**：用户可新增/编辑/删除自己的创作规则（名称 ≤30 字，规则 ≤2000 字）
4. **规则编排**：勾选多个技能后一键生成结构化提示词预览，支持编辑后应用到镜头
5. **智能检测**：自动检测提示词冲突（如推近+拉远并存、固定镜头+移动运镜冲突）
6. **项目级规则**：支持项目创作设置中配置默认规则，叠加到个人技能之上

### 数据存储

- 用户自定义技能存储于 `localStorage`（按用户 ID 隔离）
- 当前为纯本地方案，未连接云端同步

## 使用流程

```
选择模式 → 输入/选择分镜内容 → 勾选创作技能 → 生成规则预览 → 编辑确认 → 应用到镜头
```
