# Spec · 会员档位与积分商业化配置规范

> 版本：v1.0 · 2026-08-31
> 状态：生效中（与代码实现一致）
> 唯一事实来源：`src/app/pricing/data.ts`（定价配置）、本文档引用的组件文件
> 适用范围：会员档位、积分体系、用户充值、个人中心设置、活动邀请

---

## 0. 术语

| 术语 | 定义 |
|------|------|
| 积分 | 平台统一算力货币，`1 元 = 10 积分`，不可提现、不可转赠 |
| 会员积分 | 订阅会员后按月下发的积分，30 天有效，到期重置 |
| 充值积分 | 按量付费购买的积分，365 天有效 |
| 赠送积分 | 签到/活动/邀请发放的积分，签到积分当日清零 |
| 席位 | 团队版计费单元，3~10 席，积分池全员共享 |

## 1. 会员档位配置（MemberPlan Spec）

### 1.1 Schema 定义

```ts
type MemberPlan = {
  id: string;              // 档位唯一标识（trial/standard/advanced/premium/pro）
  name: string;            // 展示名（体验版/标准版/进阶版/高级版/专业版）
  tagline: string;         // 定位短句，卡片副标题
  monthlyPrice: number;    // 连续包月价（元/月，个人价）
  bonusCredits: number;    // 限时赠送积分（含在 monthlyCredits 内）
  monthlyCredits: number;  // 每月下发积分（含赠送）
  conversion: string;      // 换算文案，如 "¥10=110"
  maxImages: number;       // 每月约合可生成图片张数
  maxSeconds: number;      // 每月约合可生成视频秒数
  storageGb: number;       // 云存储空间（GB）
  concurrency: number;     // 同时生成任务数（并发）
  projects: number;        // 可创建独立创作项目数
  channel: string;         // 加速通道等级（基础级/标准级/旗舰级）
  commercialLicense: string; // 商用授权（个体户/企业）
};
```

### 1.2 当前配置（5 档）

| 字段 | trial 体验版 | standard 标准版 | advanced 进阶版 | premium 高级版 | pro 专业版 |
|------|------------|---------------|---------------|--------------|----------|
| monthlyPrice | 69 | 249 | 599 | 999 | 2299 |
| monthlyCredits | 724 | 2,739 | 6,589 | 10,989 | 26,668 |
| 年付折合月价 | 46 | 167 | 401 | 669 | 1,540 |
| maxImages / maxSeconds | 724 / 144 | 2,739 / 558 | 6,589 / 1,317 | 10,989 / 2,197 | 26,668 / 5,333 |
| concurrency | 8 | 12 | 20 | 30 | 60 |
| storageGb | 60 | 100 | 300 | 600 | 900 |
| projects | 10 | 20 | 30 | 50 | 80 |
| channel | 基础级 | 标准级 | 标准级 | 旗舰级 | 旗舰级 |
| commercialLicense | 个体户 | 个体户 | 企业 | 企业 | 企业 |

全档位通用权益：去水印、积分按月下发（30 天有效）。

### 1.3 周期与折扣规则

| 规则 | 配置 | 说明 |
|------|------|------|
| 周期选项 | `CYCLES = [连续包月, 连续包年]` | 连续包季已下线，不再恢复 |
| 年付折扣 | `yearlyMonthlyPrice = round(monthlyPrice × 0.67)` | 年付 = 约 8 个月价格用 12 个月 |
| 折扣文案 | `yearlyDiscountLabel()` →「低至67折」 | 取全档位最低折扣率，**数据驱动，禁止硬编码** |
| 月付/年付权益 | 完全一致 | 差异仅在价格，权益不参与周期决策 |

### 1.4 团队版配置

```ts
TEAM_BASE_SEATS = 3;   // 起售席位
TEAM_MAX_SEATS = 10;   // 席位上限

团队月价   = cycleMonthlyPrice × 2 + (席位 − 3) × round(cycleMonthlyPrice × 0.5)
积分池/月  = monthlyCredits × (2 + 0.5 × (席位 − 3))
加席单价   = round(个人版当前周期月价 × 0.5)   // 与周期联动
```

- 团队版 = 个人版 5 档的席位化打包，**不是独立套餐**，无独立配置项
- 团队版为单次购买、无自动续费；个人版默认连续订阅
- 发票仅支持团队版订单

### 1.5 档位配置约束（变更时必须满足）

1. `id` 全局唯一；档位顺序即展示顺序，按价格升序排列
2. `monthlyPrice`、`monthlyCredits`、`concurrency`、`storageGb` 随档位**单调递增**
3. `monthlyCredits` 必须 ≥ `bonusCredits`（赠送含在总额内）
4. `conversion` 文案须与 `monthlyCredits / (monthlyPrice / 10)` 实际汇率一致
5. 商用授权只允许「个体户商用授权」「企业商用授权」两种取值
6. 调整年付折扣系数（0.67）时，无需改任何文案，`yearlyDiscountLabel()` 自动联动

## 2. 积分体系

### 2.1 三类积分

| 类型 | 获取方式 | 有效期 | 扣除优先级 |
|------|---------|--------|-----------|
| 赠送积分 | 每日签到（+20）、邀请活动、兑换码、平台活动 | 签到积分当日清零；活动积分以活动规则为准 | 1（最先扣） |
| 会员积分 | 会员订阅按月下发 | 到账起 30 天，到期重置 | 2 |
| 充值积分 | 现金充值 | 365 天 | 3（最后扣） |

**扣除原则**：优先消耗有效期短的积分，同类型先进先出，最大限度保留用户付费充值积分。

### 2.2 消耗与返还

- 视频按秒扣费、图片按张扣费；提交任务前展示预估消耗
- 生成失败扣除的积分 **24 小时内返还**原账户
- 明细可查：个人中心「积分明细」（类型/单号/变动/余额/详情，支持日期+类型筛选）与「任务明细」（任务/状态/消耗，失败显示「不扣费（失败返还）」）

## 3. 用户充值（RechargeTier Spec）

### 3.1 Schema 定义

```ts
type RechargeTier = {
  id: string;            // 档位唯一标识
  price: number;         // 价格（元）
  credits: number;       // 到账积分
  bonusLabel?: string;   // 加赠角标，如 "+20%"
  note?: string;         // 备注，如 "首充专享 · 终身一次"
  recommended?: boolean; // 是否标记「推荐」
};
```

### 3.2 当前配置（6 档）

| id | price | credits | 加赠 | 角色 |
|----|-------|---------|------|------|
| first | ¥10 | 150 | +50% | 首充专享，终身一次 |
| t50 | ¥50 | 500 | — | 锚点起点 |
| t100 | ¥100 | 1,100 | +10% | 轻量主力 |
| t300 | ¥300 | 3,450 | +15% | 腰部承接 |
| t600 | ¥600 | 7,200 | +20% | **推荐档**（recommended） |
| t950 | ¥950 | 10,500 | 送1,000等值 | 天花板锚点 |

约束：加赠比例随价格单调递增；`recommended` 至多 1 个；`first` 档必须保持最低价。

### 3.3 首充规则

- 账号级一次性权益：支付成功写入 `localStorage` key `first_charge_done`，卡片置灰「已使用」，永不复购
- **SSR 安全**：经 `useSyncExternalStore` + 自定义事件订阅读取，服务端恒返回 `false`，禁止在 SSR 直接读 `localStorage`
- 二次转化：首充成功页展示「升级年费会员」CTA，跳转 `/pricing#membership`

### 3.4 活动加赠

- 模型首发等活动期间充值加赠最高 **+70%**（当前：Seedance 2.5 首发，2026.8.14 14:00 – 9.17 14:00）
- 活动加赠不与常规档加赠叠加，**取高者**；活动结束后恢复原价，已购权益不受影响

### 3.5 收银台（CheckoutDialog）

三步标准流程，订单结构 `CheckoutOrder`：

```
① 订单确认：商品标题 + 权益清单（积分/席位/折扣明细）+ 应付金额 + 支付方式
② 支付处理：模拟网关（预留真实支付网关接入点，替换 pay() 即可）
③ 支付成功：结果提示 + 二次转化 CTA（仅首充场景）
```

- 支付方式：微信支付 / 支付宝 / 余额支付（前端模拟）
- 团队订单展示「N 席位 · 含加席 ×M · 积分池」明细
- ESC / 遮罩可关闭，支付处理中防误触

## 4. 个人中心设置

### 4.1 入口结构

```
侧边栏头像 → AccountDropdown（下拉菜单）
  ├─ 用户信息：头像（更换）/ 昵称（编辑资料 → profile）
  ├─ 积分余额（点击 → 积分明细）+ 每日签到（会员 +20；非会员引导订阅）
  ├─ 邀请好友赚积分（品牌渐变胶囊 → 邀请活动弹框）
  ├─ 个人中心与作品（→ profile）
  ├─ 消息中心（→ MessageCenter，含未读数）
  ├─ 团队版（→ TeamDialog）
  ├─ 兑换码（→ RedeemDialog）
  └─ AI 水印（→ AiWatermarkDialog）
```

### 4.2 账户管理弹框（AccountDialog）

全屏弹框，左侧菜单 5 Tab + AI 水印：

| Tab | id | 内容 |
|-----|-----|------|
| 个人资料 | profile | 头像/昵称编辑、退出登录（危险色按钮，退出返回登录页） |
| 积分充值 | charge | 充值记录表：订单号/可用类型/金额/积分/支付状态/创建与支付时间 |
| 积分明细 | points | 筛选（日期区间 + 类型）+ 明细表：时间/类型/交易单号/积分/交易后余额/详情，分页 |
| 任务明细 | task | 生成任务表：时间/任务/状态/积分消耗（失败 0 扣费） |
| 邀请好友 | invite | 邀请统计 3 指标、邀请码复制、30 天失效提示、邀请记录表 |

### 4.3 兑换码（RedeemDialog）

- 输入自动 `trim().toUpperCase()` 后校验；Enter 快捷提交；空输入禁用确认按钮
- 成功态展示到账积分，并引导至「积分明细」查看
- 当前为 Mock 校验表 `VALID_CODES`（如 BOLLO2026 → 500），**接入后端时替换为服务端校验接口**

### 4.4 AI 水印设置（AiWatermarkDialog）

- `role="switch"` 开关控制「去 AI 水印」，默认开启
- 开启后不再添加「AI 生成」明水印，保留「bollo」品牌水印
- 含法规告知文案与责任声明，保存前需用户确认

## 5. 活动邀请（InviteCampaignDialog Spec）

### 5.1 活动规则

| 规则项 | 配置 |
|--------|------|
| 活动周期 | 截止 2026.09.27 |
| 被邀请人奖励 | 注册即得 100 积分 |
| 邀请人奖励 | 阶梯制：第 1-10 人 60 积分/人 → 第 11-20 人 120 积分/人 → 第 21-50 人 150 积分/人 |
| 累计上限 | 3,000 积分/人（达上限后仍可建立邀请关系，不再发奖励） |
| 失效条件 | 被邀请用户超过 30 天未订阅会员，邀请失效 |
| 奖励判定 | 以好友注册成功时的活动规则为准 |

### 5.2 交互流程

```
主视图：标题/奖励摘要 → 双 CTA（复制邀请链接 / 生成邀请二维码）
  → 邀请步骤 3 卡片 → 我的奖励 3 指标（累计获得/成功邀请/当前奖励档位）
  → 活动规则（折叠面板，阶梯奖励表）
二维码视图：QRCode.toDataURL 实时生成（200px, ECC-M）→ 保存 PNG 下载
```

- 邀请链接格式：`https://bollo.ai/i/{邀请码}`，好友打开注册后自动绑定邀请关系
- 复制反馈 2 秒后自动恢复文案

### 5.3 活动运营组件（全局）

| 组件 | 位置 | 频控 |
|------|------|------|
| 活动 Banner | /home 顶部 sticky | 关闭后写 Cookie 持久 1 年 |
| 活动弹窗 | /home 首屏，双页轮播 | 每日一次（localStorage 按日去重） |

两者均 `next/dynamic ssr:false` 加载，Cookie/localStorage 不进 SSR。
