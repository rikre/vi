# 项目创作设置

入口位于项目右上角，不依赖当前页签。覆盖 `/comic/:id` 短剧工作台、重绘工作台，以及 `/project/:id` 项目页。

三类配置互相独立：

| 类别 | 默认方案 | 使用位置 |
| --- | --- | --- |
| 分镜 Agent | 叙事分镜、重绘还原 | 分镜页方案摘要、分镜提示词规则预览 |
| 资产提炼 Agent | 一致性提炼、精简资产 | 资产页当前方案摘要、设置内请求预览 |
| 提示词润色 | 清晰表达、画面稳定 | 单视频润色及去瑕疵规则预览 |

每类支持多个方案、预设编辑、复制新建、删除与默认选择。测试使用当前未保存草稿，不调用模型。保存后按项目 ID 持久化，不覆盖现有剧本／镜头／资产。取消有改动时需确认。移动端直接显示三个类别。

旧剧本侧栏的设置改名为“剧本偏好”，仅保留局部创编角色与风格；不再作为三大生产技能入口。两类设置不会自动互相覆盖。

## 执行边界

当前仍是浏览器存储与规则编排，不代表真实模型路由已接通。分镜／润色预览会读项目默认规则；资产生成仍是既有模拟逻辑，不能宣称新规则已经改变模型提炼结果。正式接入时需将同一项目配置传到鉴权后的任务服务，并记录每次任务的配置版本。

验证包含：旧工作台无需打开剧本即可配置、三类方案选择、自定义规则测试、刷新保存、分镜预览读取规则、重绘入口、项目隔离和移动端布局。
