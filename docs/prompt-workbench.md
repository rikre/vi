# 提示词与自定义技能

## 当前交付

- 技能页：“提示词与自定义技能”打开工作台。
- 项目详情：“提示词”页签读取已有分镜；旧版分镜工作台也提供入口。
- 分镜提示词、单视频润色、去瑕疵三个模式，共用输入、技能选择和预览区。
- 内置镜头叙事、动作与运镜、角色一致性、画面稳定四项规则。
- 自定义技能可创建、编辑、删除，在当前浏览器按用户 ID 隔离保存。
- 短剧项目支持将预览保存到镜头 prompt 字段及单步撤销；剧本类项目目前支持复制，不直接覆盖剧本。
- 项目创建页用“全剧智能体”名称说明后续流程，没有新增自动生成或收费行为。
- Logo 复用用户指定的官方 PNG 地址。

## 能力边界

当前是本地规则编排，不是语言模型生成。原文完整保留，技能规则作为文本约束加入预览。去瑕疵只检查少量明确的提示词冲突并提供一致性规则，不是视频修复，不保证模型输出质量。不扣积分，不自动上传内容。

自定义技能不跨设备同步；项目沿用现有浏览器存储机制。应用不修改画面描述，也不触发视频生成。跨项目权限、云端技能版本、批处理、模型调用和扣费仍需后端支持。

## 后续真实智能体接入

建议采用“剧本与分镜上下文 → 用户选择的技能 → 服务端模型调用 → 差异预览 → 用户确认应用”。服务端需要校验项目归属、记录技能版本、支持超时取消与失败回退、控制用量。不能把自定义规则作为系统权限或执行代码。
