# Bollo 商业体验架构（2026-10-26）

## 1. 原则与边界

保留现有 App Router、侧栏六项主导航、首页创作流程、运营位数据、鉴权与权限。此次升级只调整信息层级、视觉层级与交互反馈，不新增业务承诺，不改变接口。

设计关键词：**克制、专业、可信、创作效率**。品牌柠檬色只用于当前任务、关键操作和状态，不让多个促销按钮同时争夺注意力。

## 2. 信息架构

| 层级 | 内容 | 体验任务 | 实现边界 |
| --- | --- | --- | --- |
| 全局层 | 活动条、侧栏、账户、消息、帮助 | 随时定位、回到主任务、访问账户 | AppShell / Sidebar / AccountDropdown 共享 |
| 首页主任务 | 做短剧、写剧本、项目配置、创建 | 让用户在首屏理解并完成第一步 | HomeHero 保留原路由与参数 |
| 能力层 | 视频、图片、音乐、超分、去字幕、数字人 | 从完整项目分流到单项能力 | home_quick_actions 优先，静态数据兜底 |
| 决策层 | 热榜、活动、IP、艺人、剧场 | 提供灵感、趋势与内容可信度 | 保留运营位与既有跳转 |
| 商业层 | 邀请、订阅、积分、团队 | 在上下文内转化，不遮挡创作任务 | 保留 pricing / team / account 流程 |

## 3. 页面结构

1. **识别区**：Bollo 标志、用户群、邀请和订阅；邀请降为品牌弱按钮，订阅为唯一高亮商业按钮。
2. **价值区**：一句话说明产品价值，辅以“AI 创作工作台”状态，不增加不可验证的数据。
3. **任务区**：做短剧/写剧本是页面视觉中心；项目名、上传、模式、比例与创建按配置顺序组织。
4. **能力区**：六张快捷卡保持三档响应式；用标题、描述、图片和方向反馈表达可点击性。
5. **内容区**：热榜、IP、艺人和剧场沿用现有模块，不在本轮更改业务内容。

## 4. 组件与状态规则

- **页面背景**：深色底上使用极低亮度品牌/信息色环境光，不用大面积渐变替代内容层级。
- **主任务面板**：`surface` 到 `background` 的轻微过渡、1px border、22px 圆角；不使用阴影堆叠层级。
- **主按钮**：品牌底 + 品牌前景字；同一视区只保留一个视觉最强主操作。
- **次按钮**：透明/弱表面 + border；hover 只提升表面和边框，不改变布局。
- **卡片**：统一 88–104px 高度区间、图片右侧融合、2px 上浮、border 增强；焦点环与 hover 等价可见。
- **弹层**：`surface-elevated`，账户头部与操作区分组；关闭状态必须退出 Tab 顺序和无障碍树。
- **动效**：160–300ms；仅 transform/color/opacity；尊重 reduced-motion。
- **响应式**：>=1280 六列，768–1279 三列，<768 单列；移动抽屉与账户菜单不溢出视口。

## 5. 核心交互验收

- 做短剧/写剧本、Agent/人工、风格、比例和创建按钮保持原行为。
- 前五个快捷入口到 `/tools`，数字人到 `/library`；运营位覆盖规则不变。
- 管理员/非管理员、团队/无团队、签到/未签到文案与权限不被视觉改版改变。
- Esc、点击空白、Tab 顺序、焦点可见、移动抽屉和窄屏均通过浏览器回归。

## 6. 本轮实施范围

共享设计 token 与卡片基底、首页价值区/主任务区/快捷入口、共享侧栏细节、账户菜单视觉和关闭态可访问性。其他路由继承共享壳层，不在本轮重写其业务页面。
