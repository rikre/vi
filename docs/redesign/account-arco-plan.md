# 个人设置 Arco 风格统一方案

## 目标与边界

以项目现有本地 Mock 数据为唯一演示基准，不改变鉴权、权限、积分、订单、邀请和水印业务规则。个人设置参考 Arco Design 官方控件规范，以本地 React 组件实现，避免额外引入依赖和主题冲突。

官方依据：Arco Button/Input 的 mini、small、default、large 高度分别为 24/28/32/36px；默认推荐 32px；输入标签尽量不超过 6 个汉字，标签与辅助文字靠近控件。

## 设计 token

- 底色：`#0d0d0d`；面板：沿用 `surface`；浮层：沿用 `surface-elevated`；文字：`#ffffff` / `muted-foreground`；主操作：`#c8ff71`；危险：语义 `danger`。
- 字体：MiSansVF 为唯一界面字族；正文 14px，辅助 12px，表格 13px；等宽字体只用于订单号和邀请码。
- 控件：默认 32px、小型 28px、主操作 36px；圆角 6px；同一表单只使用一个尺寸体系。
- 状态：默认 / 悬停 / 聚焦 / 禁用 / 错误 / 成功必须可辨认；焦点使用品牌色 2px 环。

## 版式

桌面：

```text
┌ 账户管理 -------------------------------------- 关闭 ┐
│ 个人资料 │ 页面标题                                  │
│ 订单充值 │ 筛选：单号  开始日期  结束日期  类型  查询 │
│ 积分明细 │ ┌ 表格容器（自身滚动）──────────────────┐ │
│ 任务明细 │ │ 表头 / 数据行 / 状态标签 / 空状态       │ │
│ 邀请好友 │ └───────────────────────────────────────┘ │
│ 生成水印 │ 分页                                      │
```

窄屏：左侧导航改为顶部横向导航，内容单列；表格不压缩列宽，只在表格内部横向滚动。

## 中文与一致性

删除装饰性英文 eyebrow 和 Capabilities；Agent 模式改智能模式；ID 改用户编号；AI 水印改生成水印。品牌、模型名、文件格式和既有 Skills 入口保留。

## 自检

不引入 Arco 默认蓝色，不把所有区域都做成相同卡片，不增加无意义渐变、英文标签、编号和装饰线。唯一视觉重点仍是当前主操作；其他控件保持安静、可预测。

## 三轮测试 Loop

1. V1：组件化与中文文案 → 类型/单测/浏览器走查。
2. V2：根据 V1 证据修正响应式、可访问性和筛选边界 → 复跑。
3. V3：跨页面一致性终检、全链路回归、冻结报告；不增加新样式。
