# Bollo 设计测试 Loop 报告

## 基准

- 数据：项目现有本地 Mock 数据；不连接或修改真实账户数据。
- 控件：Arco Design 官方尺寸与输入规范，本地 React 组件实现。
- 浏览器：本机 Chromium，1440×1000、768×1000、390×844。
- 约束：不放宽业务断言，不改变权限、路由和扣费规则。

## V1：组件化与中文统一

### 已完成

- 新增 Arco 风格按钮、输入、下拉、标签、表格、开关组件。
- 个人设置资料、充值、积分、任务、邀请和水印控件接入统一组件。
- 表格独立横向滚动；账户导航提供窄屏布局。
- 删除装饰性英文标签；Agent 模式改智能模式；ID 改用户编号；AI 水印改生成水印。

### 测试与走查

- TypeScript：通过。
- ESLint（本轮文件）：0 errors，保留既有 img 优化 warnings。
- Vitest：11/12 通过；复制邀请码用例因 user-event 剪贴板桩覆盖自定义 spy 失败，已修正测试初始化顺序，业务代码未改。
- 1440px：筛选、表格、分页布局正常。
- 390px：页面 scrollWidth=390，无整页横向溢出；表格容器宽 358px、内容宽 1050px，可独立滚动。

## V2：响应式与无障碍修正

### 修正

- 账户内容改用命名 section，消除重复 main 地标。
- 表格区域支持键盘聚焦与方向键滚动，增加窄屏中文滑动提示。
- 分页增加 group 角色；提升账户详情和水印弹框层级，避免底层移动菜单透出。

### 复跑

- 相关 Vitest：12/12 通过（账户 5 + 侧栏 7）。
- 账户积分页 axe：0 violations、0 incomplete。
- 390px：整页无横向溢出；表格容器可聚焦，方向键滚动实测 scrollLeft 从 0 到 40。

## V3：功能闭环与一致性终检

### 走查与修正

- 修复水印子弹框与账户详情同时监听 Esc 导致误关底层页面的问题；现在只关闭最上层。
- 新增嵌套弹框回归测试；账户相关测试增至 6 条。
- 充值类型筛选、任务失败返还、邀请码复制、积分空结果/重置、昵称保存、换绑验证码、水印保存均通过。
- 首页写剧本、模型切换、智能模式、风格库、用户群、帮助反馈及快捷入口实机走查通过。
- 风格库 Hot/New 改热门/最新，并使用语义状态色；首页不再出现 Capabilities、Agent 模式或 AI Studio 装饰标签。

### 最终结果

- TypeScript：通过。
- 相关 Vitest：13/13 通过（账户 6 + 侧栏 7）。
- 本轮文件 ESLint：0 errors；保留 12 个既有 img 优化 warnings。

### 遗留边界

- 本轮验收针对本地 Mock 与相关功能测试；未把 Mock 数据当作真实接口验收。
- 未在 dev 服务运行时执行生产构建或全量测试；既有全量 Vitest worker 问题与 Node >=24 环境要求需单独处理。
- 邀请活动 Mock 文案中的截止日期需要业务侧另行确认，本轮不擅自改写活动规则。
