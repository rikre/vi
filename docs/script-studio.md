# 剧本编辑与项目创编配置

入口：`/project/{id}?tab=script`。旧版剧本工作台及重绘工作台提供跳转入口，保留原有章节和资产操作。

## 已实现

- 用项目真实剧本替换静态示例，允许编辑人物、结构、场景与对白。
- 草稿在浏览器中保存；“保存版本”建立完整正文快照。
- 历史列表显示时间、修改类型和创编要求，恢复会新增版本，不删除旧历史。恢复前的未提交草稿另存一份。
- 保存完整剧本同步 `scriptContent` 和短剧项目 `scriptChapters`，已有分镜、资产和视频不自动重新生成。
- 项目级助手名称、角色规则、默认风格、保留对白开关，以及自定义技能增删改和启停。
- 弹窗用未保存的配置编排测试请求，取消不会影响项目；保存只作用于当前项目。
- 精确替换支持预览后确认；创编请求支持复制，以及粘贴／手动编辑完整修改稿后保存。
- 创编版本记录使用的配置快照。

## 边界

尚未接入语言模型。结构和人物创编只编排请求，不自动生成新剧情；精确替换是文本操作，不是语义理解。配置测试是请求预览，不是模型测试，不扣积分。

项目、草稿、历史、配置沿用当前本地浏览器存储，不跨设备同步，也不构成服务端用户权限隔离。存储失败显示错误，用户需复制备份。历史没有自动清理；长剧本大量版本可能达到浏览器配额。

保存完整剧本会将章节表示同步为一个“完整剧本”章节；原正文保留在初始历史里。与旧版章节编辑器交替使用时，应先保存并刷新页面，避免并行编辑。后续可在统一后端中进一步实现章节级版本和并发冲突控制。
